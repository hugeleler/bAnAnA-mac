常见问题

菜单里有小香蕉，但系统设置的键盘列表里没有

当前包是临时签名，没有 Developer ID，也没有公证。系统设置会隐藏被 Gatekeeper 拒绝的输入法。这不是皮肤或词库的问题。要出现在系统设置里，需要用 Developer ID 签名并对安装包公证。

检查更新说已经是最新版，但没有「版本历史记录」

「版本历史记录」只在更新频道最新一条带有发布说明链接时出现。说明页是：

https://hugeleler.github.io/bAnAnA-mac/changelog.html

频道文件不在 main 分支。若客户端仍在请求 main 上的旧地址，那个地址已经删除，检查会失败。已安装的 1.1.2.0 需要把更新地址指到上面的 github.io 链接。

和鼠须管互相抢配置

确认小香蕉的用户目录是 ~/Library/bAnAnA，并且里面有自己的 installation.yaml。若两个进程曾经共用一个目录，先退出其中一个，再各自重新部署。

换了皮肤没有变化

「更换皮肤」写的是 mac.custom.yaml 里的 style/color_scheme 和 style/color_scheme_dark。只改其中一个时，亮色和暗色会不一致。改完要部署成功。看菜单是否提示「部署完成。」

部署失败

打开「日志...」。常见原因是 yaml 缩进错了，或补丁的键路径不存在。先恢复最后一次改动，再重新部署。
