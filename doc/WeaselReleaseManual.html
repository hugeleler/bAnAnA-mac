Windows 发布说明

Windows 端的版本列表与 macOS 分开。

已有的 Windows 产品页使用 gh-pages 存放频道文件，例如 lite 与 pro 两份列表，仓库是 hugeleler/bAnAnA。那些文件描述的是 Windows 安装包，不是 macOS 的 pkg。

新的 Windows 前端仓库是 bAnAnA-windows。它的频道同样不应放到 main 上给人浏览源码时直接看见。发布 Windows 安装包时，沿用同一规则：gh-pages 放频道和更新记录，Release 放 exe，注册表和用户目录使用 bAnAnA，不使用 Weasel。

macOS 的 appcast.xml 不能填进 Windows 的更新地址。两端的安装包格式不同。
