入门

安装

下载 小香蕉 1.1.2 的 pkg，打开安装器。安装结束后，输入法位于：

/Library/Input Methods/bAnAnA.app

在菜单栏输入法菜单里选择「小香蕉」。简体输入源 id 是 im.banana.inputmethod.bAnAnA.Hans，繁体是 im.banana.inputmethod.bAnAnA.Hant。

当前安装包尚未使用 Developer ID 签名，也未公证。macOS 的 Gatekeeper 会拦住未签名安装包的直接打开。系统设置里的键盘列表也可能不列出未通过 Gatekeeper 的输入法。签名和公证的说明见 macOS 发布说明。

第一次输入

1. 切到小香蕉。

2. 输入拼音，空格或数字上屏。

3. 需要改外观时，点输入法菜单里的「更换皮肤」。

4. 改完用户目录里的 yaml 后，点「重新部署」。

菜单

菜单作用
更换皮肤弹出皮肤列表，写入 mac.custom.yaml 的亮色和暗色方案
重新部署重新编译方案和词库
同步用户数据按用户目录里的同步设定合并词典快照
日志...打开本次运行的日志目录
用户设定...打开 ~/Library/bAnAnA
在线文档...打开本维基
检查新版本...读取更新频道，和当前版本比较

检查新版本不会在后台自动跑。只有点这个菜单才会请求更新频道。
