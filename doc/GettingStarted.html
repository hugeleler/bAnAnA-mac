入门

先按系统装好对应安装包，见 下载与安装。版本都是 1.1.2.5。

macOS

  1. 打开 bAnAnA-1.1.2.5.pkg。
  2. 输入法在 /Library/Input Methods/bAnAnA.app。
  3. 菜单栏输入法菜单选「小香蕉」。简体源 im.banana.inputmethod.bAnAnA.Hans，繁体 im.banana.inputmethod.bAnAnA.Hant。
  4. 拼音后空格或数字上屏。换皮肤、重新部署、检查更新都在输入法菜单。

Windows

  1. 运行 bAnAnA-1.1.2.5-setup.exe。
  2. 在系统输入法列表里启用小香蕉。
  3. 用户数据在 %AppData%\bAnAnA。不要写到 Weasel / %AppData%\Rime。

Android

  1. 安装 bAnAnA-1.1.2.5.apk（arm64）。
  2. 系统设置里启用小香蕉，并允许在该输入法中显示。
  3. 打开应用改方案、皮肤、候选翻页、候选个数、语言模型。

iOS

  1. 没有公开 IPA。用 Xcode 把主应用装到真机，或以后用付费账号走 TestFlight。
  2. 系统设置 → 键盘 → 添加「小香蕉」，打开「允许完全访问」。完全访问关着时，键盘读不到 App Group 里的方案和偏好。
  3. 主应用 bundle im.banana.inputmethod.bAnAnA，键盘 im.banana.inputmethod.bAnAnA.keyboard。工具栏第一项用 banana:// 打开主应用，同样需要完全访问。
