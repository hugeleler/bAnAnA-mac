代码

小香蕉的 macOS 前端源码在仓库的 mac/，Windows 前端在 windows/，方案和词库在 data/。

macOS 工程是 mac/bAnAnA.xcodeproj。和输入直接相关的路径：

  • 应用入口和用户目录：mac/sources/Main.swift。用户目录固定为 ~/Library/bAnAnA。
  • 菜单、部署、更新、在线文档：mac/sources/bAnAnAApplicationDelegate.swift。
  • 按键和候选：mac/sources/bAnAnAInputController.swift。

在线文档菜单打开的就是本维基。更新频道的地址写在 mac/resources/Info.plist 的 SUFeedURL，指向 GitHub Pages，不指向 main 分支。

改按键处理时保持现有的按键传递顺序。Caps Lock 要在改变锁定状态之前交给系统。带 Command 的组合键应交回系统，而不是当成编码。

引擎源码不在这个前端仓库里改产品行为。方案能表达的，用方案和补丁表达。
