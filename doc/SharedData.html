共享文件夹

共享文件夹在应用包内：

/Library/Input Methods/bAnAnA.app/Contents/SharedSupport

这里是随版本发布的方案、词典和 mac.yaml。所有用户共用这一份。用户自己的修改不要放这里，升级或重新安装会换掉这个目录里的文件。

和用户文件夹的关系

共享文件夹给出默认值。~/Library/bAnAnA 里的补丁覆盖默认值。部署时引擎把两边合成一份，编译进用户目录的 build/。

Windows 端的共享数据在小香蕉的安装目录里，用户数据仍在 %AppData%\bAnAnA。两端的皮肤文件名不同，方案 id 可以相同。
