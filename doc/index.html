小香蕉

小香蕉是四端中文输入法。显示名「小香蕉」，仓库与安装包名 bAnAnA。现行版本 1.1.2.5。

组字由 librime 1.17.0 完成。方案、词库、皮肤按方案包分发。安装包不带语言模型文件（.gram）；语言模型在 Mac / Windows / Android 里按需下载。

从这里开始

  • 下载与安装、入门
  • 说明书：桌面按键、手机键盘、候选翻页
  • 方案包：缺省「小香蕉」与「白霜拼音」
  • 语言模型
