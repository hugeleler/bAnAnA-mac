小香蕉 1.1.2.2

最低系统版本是 macOS 13。

更新记录不放在仓库 main 分支，而在发布页和更新频道：

更新记录

Windows

Windows 安装包在独立仓库 bAnAnA-windows。不要把 macOS 的 pkg 拿到 Windows 上用。

还没有安装包的端
