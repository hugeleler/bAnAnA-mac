下载与安装

现行版本一律 1.1.2.5。同一版本换包不会让已装客户端弹出「有新版本」；要换包就直接装发布链接。

端文件最低系统发布
macOSbAnAnA-1.1.2.5.pkgmacOS 13bAnAnA-mac
WindowsbAnAnA-1.1.2.5-setup.exeWindows 10 x64 / ARM64bAnAnA-windows
AndroidbAnAnA-1.1.2.5.apkAndroid 7，仅 arm64-v8abAnAnA-android
iOS无公开 IPAiOS 16，iPhone 与 iPadbAnAnA-ios 只作通道；装机用 Xcode / TestFlight

不要把 pkg 拿到 Windows 上用，也不要把 IPA 当 APK 发。

检查更新各自读自己的 appcast，互不相通：

  • macOS appcast.xml · changelog
  • Windows appcast.xml
  • Android appcast.xml
  • iOS appcast.xml

安装包只带缺省方案数据（目前发行里仍含 banana 与 frost 两套方案根）。不带 .gram。额外皮肤和语言模型从目录下载，见 语言模型。
