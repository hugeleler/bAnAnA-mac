输入方案

一份方案描述「这个输入法如何把按键变成字」。小香蕉当前主方案文件是共享目录中的 banana.schema.yaml，方案 id 是 banana。

方案里有什么

  • schema：id、显示名、版本、依赖的其他方案。
  • switches：选单里的开关，例如中英、标点、简繁。
  • engine：处理器、分段器、翻译器、过滤器的名单，按列出的顺序工作。
  • 拼写、按键绑定、标点、词典引用：决定编码和上屏。

处理器负责按键。分段器负责把一串编码切成段。翻译器查词典。过滤器改候选顺序或做简繁、表情一类的后处理。调换名单顺序会改变按键被谁先看见。

词典

词典源文件前半是 YAML 头，后半是码表。码表字段用制表符分隔。方案通过词典名引用它，不把词条抄进方案文件。

修改方式

不要直接改 SharedSupport 里的 banana.schema.yaml。在 ~/Library/bAnAnA/banana.custom.yaml 写 patch。新方案则把完整的 *.schema.yaml 放进用户目录，部署后在选单里启用。

依赖方案（混合编码、反查、英文等）随主方案列出。缺了依赖，部署日志会报找不到方案或词典。
