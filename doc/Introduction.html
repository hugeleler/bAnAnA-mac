简介

小香蕉在菜单和系统输入法列表里的显示名是「小香蕉」。安装包和仓库名是 bAnAnA。

它做三件事：

1. 向系统注册输入法，接收按键。

2. 把按键交给输入法引擎，取回候选和上屏文字。

3. 画出候选条，并提供部署、皮肤、同步和检查更新。

打字规则写在方案里，不写死在菜单里。当前主方案 id 是 banana，定义在随应用分发的 banana.schema.yaml。macOS 上候选条的外观写在 mac.yaml。

用户改过的文件放在 ~/Library/bAnAnA。这个目录只属于小香蕉。鼠须管继续使用 ~/Library/Rime，两边的词库、皮肤和安装标识互不覆盖。

前端按 GPL-3.0 分发。输入法引擎 librime 使用它自己的 BSD 许可证。收费分发副本不取消这两份许可证：收到程序的人可以再分发，对应源码必须能拿到。
