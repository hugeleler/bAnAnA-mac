Windows 端

Windows 上的小香蕉是单独的前端，仓库是 bAnAnA-windows。它不是把 macOS 的 app 重新打包。

结构是两个进程：文本服务在目标进程内，界面和引擎在服务进程里，中间用命名管道通信。不要合并成一个进程。

用户数据默认在 %AppData%\bAnAnA。注册表主键是 Software\bAnAnA。不要再写到 Software\Rime\Weasel 或 %AppData%\Rime。

皮肤文件名是 windows.yaml。Mac 的 mac.yaml 不会在 Windows 上生效。

更新频道与安装包发布在 Windows 仓库，见 Windows 发布说明。
