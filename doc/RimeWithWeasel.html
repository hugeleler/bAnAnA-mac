Windows

Windows 上的小香蕉是独立前端，不是把 macOS 的 app 换皮。仓库与安装包：bAnAnA-windows v1.1.2.5。

文本服务在目标进程内，界面和引擎在服务进程，中间用命名管道。用户数据默认 %AppData%\bAnAnA。注册表主键 Software\bAnAnA。不要写到 Software\Rime\Weasel。

皮肤读同一套 .bskin 的 Windows 段，出厂 luna。方案包与 Mac 同一套 data/<id>/ 结构。安装包零 gram。语言模型列表、挂载、皮肤与 Mac 对齐。

现行安装包覆盖 x64 与 ARM64。更新频道见 Windows 更新频道。不要把 macOS 的 appcast 填进 Windows。
