并击

并击是在很短的时间窗里把同时按下的一组键当成一个音节，而不是按先后顺序逐键拼写。

小香蕉的 macOS 前端保留了这个时间窗，配置项在 mac.yaml：


chord_duration: 0.1

单位是秒。要改它，写到 ~/Library/bAnAnA/mac.custom.yaml 的 patch 里，然后重新部署。方案侧仍然要有对应的并击方案，只改时间窗不会把全拼方案变成并击方案。

Windows 端的皮肤文件是 windows.yaml，不要把这项只写在 mac.yaml 里就指望 Windows 生效。
