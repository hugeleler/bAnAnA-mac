macOS 发布说明

版本怎么比较

安装包里的版本号是 CFBundleVersion。更新频道里每一条的 sparkle:version 与它比较。两个字符串相同，检查结果就是「当前已是最新版本」，不会下载。

频道地址：

https://hugeleler.github.io/bAnAnA-mac/appcast.xml

这个文件和更新记录只在仓库的 gh-pages 分支，页面由 GitHub Pages 提供。main 分支不放这两份文件。

最新一条带有发布说明链接时，检查更新的对话框才出现「版本历史记录」。说明页：

https://hugeleler.github.io/bAnAnA-mac/changelog.html

安装包下载地址在 GitHub Release，不在 gh-pages。频道只描述版本、说明链接和安装包的地址、长度与签名。

当前版本

1.1.2。安装包 bAnAnA-1.1.2.pkg。最低系统 macOS 13。用户目录 ~/Library/bAnAnA。

签名

分发给别人之前，应用和 pkg 都要用 Developer ID 签名，再用 Apple 的公证服务盖章。只有临时签名的包不能当作正式发布。公证通过不等于可以上架 Mac App Store。小香蕉走 Developer ID 安装包，不走 App Store。原因见仓库许可证：GPL-3.0 的前端不能改成专有软件再上架。
