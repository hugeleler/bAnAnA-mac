macOS 更新频道

安装包版本是 CFBundleVersion。频道里 sparkle:version 与它逐字比较。相同就是「已是最新」，即使 GitHub 上刚覆盖了同版本 pkg。

频道 appcast.xml。说明 changelog.html。都在仓库 gh-pages，不在 main。pkg 在 GitHub Release。

当前版本 1.1.2.5，文件 bAnAnA-1.1.2.5.pkg。最低 macOS 13。用户目录 ~/Library/bAnAnA。

分发给别人的 pkg 需要 Developer ID 签名和公证。Sparkle 只验频道里的长度与签名。Mac App Store 不是这条通道。
