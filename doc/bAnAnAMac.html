macOS 前端

这一页说明如何在 macOS 上使用和编译小香蕉。

使用

安装、切换、菜单和用户目录见 入门 与 用户文件夹。

外观只看 mac.yaml / mac.custom.yaml。

从源码编译

在 mac/ 目录：


xcodebuild -project bAnAnA.xcodeproj -configuration Release -scheme bAnAnA -derivedDataPath build ARCHS=arm64 ONLY_ACTIVE_ARCH=YES build

产物是 mac/build/Build/Products/Release/bAnAnA.app。

安装到 /Library/Input Methods/ 需要管理员权限。替换已安装的应用时，保留包内的 SharedSupport，除非这次修改确实包含词库。替换后需要重新签名。没有 Developer ID 时只能临时签名，系统设置的键盘列表不会把它当作可分发的输入法。

用户目录是 ~/Library/bAnAnA。
