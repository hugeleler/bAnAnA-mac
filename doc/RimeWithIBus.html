IBus

IBus 是 Linux 上的输入法框架。小香蕉没有 Linux 前端，也不把 IBus 作为 macOS 或 Windows 的依赖。

若要在 Linux 上使用同一套方案，需要另做前端去调用同一套引擎和 data/ 里的方案。用户目录不能复用 macOS 的 ~/Library/bAnAnA 路径。那是 macOS 的约定。

本页只说明边界：不要把 IBus 的配置写进 mac.yaml，也不要期待小香蕉的 pkg 在 Linux 上安装。
