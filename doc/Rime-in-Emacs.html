Emacs

小香蕉是系统输入法，不是 Emacs 插件。Emacs 里的输入由 macOS 或 Windows 的输入法框架交给小香蕉，小香蕉不读取 Emacs 的按键映射文件。

方案里可以打开 Emacs 风格的编辑键，那是方案的 key_binder 选项，只影响编码编辑，不把小香蕉装进 Emacs。

不要把 Emacs 的配置目录当成 ~/Library/bAnAnA。
