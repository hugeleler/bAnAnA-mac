说明书

方案

方案包是挂载单位。缺省 banana，另有 frost。包内多个 schema（全拼、双拼、五笔、英文、九键等）在选单里切换。开关（中英、中英标点、半角全角、简繁）以方案文件为准，部署后生效。

桌面打字（macOS / Windows）

  • 数字选当前页候选。空格通常上屏高亮项。每页个数由方案 menu/page_size 决定（banana 全拼为 6，给 7–0 留声调）。
  • 逗号句号是否翻页由方案按键绑定决定，不由皮肤决定。
  • 退格删编码；编码空了交给系统。

手机键盘（Android / iOS）

Mac / Windows 只有候选条配色，没有这块虚拟键盘。手机皮肤里是同一套键位：26 功能、26 标准、46 增强、T9、英文九键、注音九键、笔画、英文、数字。布局窗口按方案声明的 keyboard.family 决定哪几块能点。

26 功能在工具栏下还有一行：左移、行首、选择、剪切、复制、粘贴、行尾、右移。有拼音时左右移动的是候选高亮，不是光标。

候选翻页与数量

  • 数量默认「随方案」。也可以改成固定 1–10 个。
  • 翻页「左右按钮」：一屏几个就几个，到边按方案页翻（随方案时 banana 就是 6）。
  • 翻页「左右滑动」：候选排成一条，手指左右滑。功能行左右色块沿这条一直走到第一个和最后一个，不再被 6 卡住。

手机还可以调键盘高度 75%–125%、宽度 60%–100%，以及左手 / 右手 / 关闭侧栏。

简繁与用户词

简繁走方案开关和 OpenCC 表。用户词写在本机用户数据里。固定短语用文本码表，UTF-8，制表符分隔，然后重新部署。

部署与日志

改 yaml、换方案、启用语言模型之后要部署。失败时看该端的日志。提示「有错误！请查看日志」时先查最近一次改动的缩进和键路径。
