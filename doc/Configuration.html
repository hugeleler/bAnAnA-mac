配置文件

小香蕉的配置是 UTF-8 的 YAML。

两类文件

  • 发布文件：banana.schema.yaml、mac.yaml、词典。随应用放在共享目录。
  • 用户补丁：同名的 .custom.yaml，放在 ~/Library/bAnAnA。

补丁的根节点是 patch。键用斜线表示层级，例如 style/color_scheme 对应 style 下面的 color_scheme。

加载顺序

同名配置先读共享目录，再用用户目录里的补丁覆盖。用户目录里一份完整的同名 yaml 也会参与覆盖。因此鼠须管目录里的文件不会影响小香蕉。

列表可以用补丁追加、删除或按位置替换。具体指令以引擎接受的补丁语法为准：__append、__prepend、__merge 这一类键写在被修改的列表旁边。不确定时，先只改一个标量，部署，看日志，再改列表。

包含

一个 yaml 可以用包含把另一份配置拉进来，避免把整份方案复制一份。包含进来的文件仍然经过同一套补丁。改公共组件时，只改那一个组件的补丁。

编译

方案和词典在部署时编译到用户目录的 build/。编译失败时菜单会提示查看日志。日志里的文件名就是出错的 yaml 或词典。

不要混用的名字

  • 前端皮肤：macOS 用 mac，Windows 用 windows。
  • 引擎内部的应用名是 banana。它决定用户数据子路径的逻辑名，不决定菜单上的「小香蕉」三个字。菜单上的名字来自应用的本地化显示名。
